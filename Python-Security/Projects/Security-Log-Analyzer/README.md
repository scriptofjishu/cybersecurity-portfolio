# Security Log Analyzer

**Project Type:** Log Analysis & Threat Detection Tool

### Description
A Python tool that analyzes security logs to detect suspicious activities such as:
- Failed login attempts
- Suspicious IP addresses
- Potential data exfiltration (email sent to suspicious domains)

### Features
- Parses log files using regex
- Detects failed login attempts
- Extracts usernames and IP addresses
- Identifies suspicious patterns
- Generates a summary report

### Technologies Used
- Python
- Regular Expressions (`re` module)
- File Handling (I/O)

### What I Learned
- Real-world log parsing techniques
- Pattern matching with regex
- Extracting meaningful security insights from raw logs
- Structuring code for security tools
