# Automated Password Strength Checker & Generator

**Project Type:** Security Automation Tool

### Description
A complete Python tool that can:
- Check the strength of any given password
- Provide detailed feedback on weaknesses
- Generate strong, random passwords based on security requirements

### Features
- Checks for:
  - Minimum length (8+ characters)
  - Uppercase & lowercase letters
  - Numbers
  - Special characters
- Real-time weakness feedback
- Strong password generator with customization
- Clean and reusable code
